# Collaboration rules
- Keep this a generic starter. Do not add credentials, real user data or proprietary business assets.
- Preserve API compatibility with the companion repositories.
- Add meaningful authorization and interaction tests for business changes.
- Java: validate DTOs, parameterize SQL, use transactions and ownership checks.
- Vue: Composition API, TypeScript, responsive accessible forms, centralized requests.
- Flutter: GetX MVC, constructor injection, localized strings, normal responsive layout, AppBar and SafeArea; no fixed-position page layouts. Run dart format, flutter analyze and flutter test.
